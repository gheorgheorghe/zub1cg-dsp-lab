ZUBoard 1CG Bring-Up Postmortem · Bug #01

A53 / R5F LPDDR4 Memory Collision

How default Vitis 2024.2 linker scripts caused Cortex-A53 and Cortex-R5F to overwrite each other in 1 GB LPDDR4—causing a silent double-crash right after a clean JTAG boot—and the exact two-part fix.

Symptom Clean JTAG Boot, Dead Ethernet Ping

make boot programmed the Stage 1.5 FPGA bitstream and loaded both processors with zero JTAG errors—yet ping 192.168.1.10 returned 100% unreachable:

Programming PL bitstream...
Loading Cortex-R5F #0...
Loading Cortex-A53 #0...
SUCCESS: ZUBoard 1CG booted! Connect host to 192.168.1.10:5000 (UDP).

$ ping -c 3 192.168.1.10
From 192.168.1.229 icmp_seq=1 Destination Host Unreachable

Root Cause Default Vitis Linker Scripts Overlap in LPDDR4

When Vitis generates standalone bare-metal apps for an AMP (Asymmetric Multi-Processing) ZynqMP system, each CPU domain independently assumes it owns all 1 GB of LPDDR4:

  • a53_net_bridge/src/lscript.ld placed A53 at 0x0000_0000 (with 6.4 MB of lwip220 .bss buffers spanning 0x0000_0000 .. 0x0062_5000).
  • r5f_realtime/src/lscript.ld placed R5F right at 0x0010_0000—dead center inside A53's lwIP RAM!

Fix Exact Changes Applied

Fix 1 — Partition 1 GB LPDDR4 in sw/build_vitis.py:
Automatically patches both auto-generated Vitis linker scripts before building so every future make sw stays collision-free: 
# A53: 0x0000_0000 .. 0x2FFF_FFFF (768 MB)
psu_ddr_0 : ORIGIN = 0x0, LENGTH = 0x30000000

# R5F: 0x3000_0000 .. 0x3FEF_FFFF (255 MB — zero overlap!)
psu_ddr_0 : ORIGIN = 0x30000000, LENGTH = 0x0ff00000
Fix 2 — Explicit IRQ Enable & ARP Timer in sw/a53_net_bridge/src/main.c:
Xilinx's bare-metal lwip220 GEM3 driver is interrupt-driven (its RX ISR pushes incoming ARP/ICMP/UDP frames into recv_q, which xemacif_input() drains). Adding explicit Xil_ExceptionEnable() and a 1 Hz etharp_tmr() ensures GEM3 interrupts always fire and ARP entries stay fresh: 
netif_set_default(&server_netif);
netif_set_up(&server_netif);
Xil_ExceptionEnable();   /* Guarantee GEM3 RX/TX IRQs fire on A53 */

...
while (1) {
    xemacif_input(&server_netif);
    XTime_GetTime(&now_t);
    if ((now_t - last_arp_t) >= (XTime)COUNTS_PER_SECOND) {
        last_arp_t = now_t;
        etharp_tmr();
    }
}
